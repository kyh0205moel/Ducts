덕트 직경·상용 규격 선정 계산기 (첨부 교재 반영)

파일 4개
1. index.html: 계산기 본체
2. manifest.json: 홈 화면 설치 설정
3. service-worker.js: 오프라인 캐시
4. 설치방법.txt: 이 안내문

교재 반영 사항
- Q 단위: m³/min
- V 단위: m/s
- 계산 직경: D = sqrt(4(Q/60)/(pi*V))
- 첨부된 상용 규격표(mm): 10, 15, 20, 25, 32, 40, 50, 65, 80, 90, 100, 125, 150, 200, 250, 300, 350, 400, 450, 500, 550, 600, 650, 750
- 교재의 선정 설명에 따라 계산 직경 이하에서 가장 큰 상용 규격을 추천합니다. 이는 계산 직경을 최대 크기로 보고, 작은 규격으로 선정하면 유속이 올라가는 방식입니다.

GitHub 업로드
1. ZIP을 압축 해제합니다.
2. GitHub 저장소 > Add file > Upload files를 엽니다.
3. index.html, manifest.json, service-worker.js를 저장소 최상위에 업로드합니다.
4. Commit changes를 누릅니다.
5. GitHub Pages의 HTTPS 주소를 온라인 상태에서 열어 캐시가 등록될 때까지 기다립니다.
6. 인터넷을 끄고 다시 열어 오프라인 작동을 확인합니다.

주의
상용 규격표는 첨부 이미지의 표를 그대로 옮긴 것입니다. 실제 현장에서는 제조사 규격과 설계 기준을 확인하세요.
기존 계산기와 같은 저장소에 업로드하면 기존 index.html이 교체될 수 있으므로 별도 저장소 사용을 권장합니다.
