덕트 직경·상용 규격 계산기 - GitHub 업로드 안내

구성 파일
1. index.html : 계산기 본체
2. manifest.json : 홈 화면 설치 설정
3. service-worker.js : 오프라인 캐시 설정
4. 설치방법.txt : 이 안내문

업로드 방법
1. ZIP을 압축 해제합니다.
2. GitHub 저장소에서 Add file > Upload files를 선택합니다.
3. index.html, manifest.json, service-worker.js를 저장소 최상위에 업로드합니다.
4. Commit changes를 누릅니다.
5. GitHub 저장소 Settings > Pages에서 Pages를 활성화합니다.
6. 배포된 HTTPS 주소를 온라인 상태에서 열고 로딩이 끝날 때까지 기다립니다.
7. 인터넷을 끄고 다시 열어 오프라인 동작을 테스트합니다.

기능
- 계산 직경(mm) 입력
- 계산 직경 이상에서 가장 작은 규격 추천
- 가장 가까운 규격 추천
- 환기량(m³/min)을 입력하면 각 규격에서의 평균 유속(m/s) 표시
- 일반적으로 쓰이는 원형 덕트 규격 후보값 목록 포함

주의
상용 규격 목록은 일반적인 후보 예시이며 제조사별 제품 규격을 보증하지 않습니다. 실제 발주 전 제조사 카탈로그와 현장 설계기준을 확인하세요.
오프라인 기능은 GitHub Pages HTTPS에서 첫 온라인 접속으로 캐시가 등록된 뒤 사용할 수 있습니다.
기존 저장소에 업로드하면 기존 index.html이 교체될 수 있으므로, 기존 계산기를 보존하려면 별도 저장소를 권장합니다.
